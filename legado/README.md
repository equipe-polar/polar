# Legado do Projeto

Esta pasta contem o codigo historico que deu origem ao projeto.
Ela existe para preservar o trabalho ja realizado e servir como
referencia tecnica para entender a evolucao do sistema.

## Importante

O codigo aqui presente NAO deve ser alterado ou excluido.
Ele representa a fundacao sobre a qual o novo sistema foi construido.

Arquivos `.env` reais foram omitidos desta copia versionada por seguranca.
As branches originais continuam preservadas no Git para consulta historica.

## Estrutura

- `branch-master/` -> snapshot da branch `master`, usada como linha principal historica do projeto.
- `branch-develop/` -> snapshot da branch `develop` antes da reorganizacao e da implantacao do novo sistema TypeScript.
